# معماری مدیریت یکپارچه‌ی آب مجتمع صنعتی (پیش‌نویس)

هدف: Auditra ابزارهای جدا نیست، یک نرم‌افزار مدیریت یکپارچه است. همه‌ی ماژول‌ها روی یک **مدل مشترک مجتمع** کار می‌کنند.

## لایه‌ها
| لایه | محتوا | وضعیت |
|---|---|---|
| ۰ دانش | بانک تجهیزات (۱۸۰)، فرمول‌ها (۱۷۷)، شاخص‌ها (۹۰)، واژگان | تمام و تأییدشده |
| ۱ مدل مجتمع | گره‌ها، جریان‌های نوع‌دار، نقاط اندازه‌گیری، سری زمانی (`db/schema.sql`) | طرح اولیه |
| ۲ مرکز داده | ورود دستی، Excel و CSV، API، درگاه صنعتی؛ اعتبارسنجی و برچسب کیفیت | طراحی |
| ۳ موتورها | ۱۰ موتور محاسبه روی مدل؛ اتصال متغیر فرمول به نقطه‌ی اندازه‌گیری (`formula_binding`) | طراحی |
| ۴ چرخه‌ی مدیریت | هشدار ← بازرسی ← فرصت ← ارزیابی اقتصادی ← اجرا ← صحه‌گذاری (`case_file`) | طراحی |
| ۵ نمایش | داشبورد، گزارش، محیط گرافیکی شبکه | بعداً |
| ۶ حاکمیت | کاربر، نقش (اپراتور، کارشناس، مدیر)، سابقه‌ی تغییرات | طراحی |

## قواعد
- هر عدد منشأ و برچسب کیفیت دارد (اندازه‌گیری‌شده، برآوردی، مشکوک، نامعتبر، گمشده).
- ذخیره‌سازی به‌صورت UTC و نمایش شمسی یا میلادی؛ مرز ماه و سال در لایه‌ی تجمیع محاسبه می‌شود.
- حد هدف، هشدار و بحرانی شاخص‌ها برای هر مجتمع و گره در `kpi_setting` است، نه در بانک مشترک.
- جدول‌های مرجع با افزودن «ردیف» (شناسه‌ی `USR`) گسترش می‌یابند.
- شاخص‌هایی که به موازنه وابسته‌اند، تا وقتی موازنه معتبر نیست با برچسب «اعتماد پایین» نشان داده می‌شوند.

## قدم‌های بعدی
۱. اجرای `db/schema.sql` روی PostgreSQL و رفع خطاها (هنوز اجرا نشده است). ۲. مجتمع نمونه و ورود داده با Excel/CSV. ۳. اجرای موازنه‌ی آب با عدم قطعیت روی مدل و نمایش نتیجه روی گراف.
